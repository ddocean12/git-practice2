The daily cycle
Command	                 When you run it
git pull	    Before you start, to get the latest
git status	    Constantly — before and after everything else
git add <file>	    When a change is ready to be included
git commit -m "..." To record a snapshot with a reason
git push            To send your commits to GitHub
git log --oneline   To see what has happened
git remote -v	    To check where "there" actually is
